# Customer Behavior Analysis Project

## Overview
This repository contains a complete end-to-end data analysis project focusing on customer shopping behavior. It is designed to provide actionable business insights from retail and e-commerce transaction data.

The project demonstrates proficiency in data manipulation, exploratory data analysis (EDA), database querying, and interactive data visualization.

## Key Features
- **Exploratory Data Analysis (EDA):** A detailed Python Notebook (`data_analysis_notebook.ipynb`) using Pandas and Matplotlib/Seaborn to clean, impute, and explore the dataset.
- **SQL Analysis:** A comprehensive set of queries (`BUSINESS_INSIGHTS.sql`) designed to answer targeted business questions regarding revenue drivers, discount effectiveness, and customer retention.
- **Interactive Dashboard:** A Power BI file (`Analysis_Dashboard.pbix`) that provides a visual overview of customer demographics, spending patterns, and geographical distributions.
- **Executive Reporting:** Professional presentations and reports (`Analysis_Presentation.pptx`, `Final_Report.pdf`) summarizing the key findings and strategic recommendations.

## Business Questions Answered
1. What are the top revenue-generating product categories?
2. Do discount strategies effectively increase the average order value?
3. How do spending habits differ between subscribed and non-subscribed users?
4. What is the impact of seasonal variation on product demand?
5. How can we categorize customers into Loyal, Returning, and New segments?

## Getting Started
1. **Database Setup:** Load the provided `customer_shopping_behavior.csv` into your preferred SQL environment. Execute `BUSINESS_INSIGHTS.sql` to generate insights.
2. **Python Analysis:** Open `data_analysis_notebook.ipynb` in Jupyter or VS Code to review the data cleaning and initial exploration process.
3. **Dashboard:** Open `Analysis_Dashboard.pbix` with Power BI Desktop to interact with the visualizations.

## Repository Structure
- `customer_shopping_behavior.csv` - The raw data.
- `data_analysis_notebook.ipynb` - Python EDA.
- `BUSINESS_INSIGHTS.sql` - SQL Queries.
- `Analysis_Dashboard.pbix` - Power BI Dashboard.
- `Analysis_Presentation.pptx` & `.pdf` - Summary Presentation.
- `Final_Report.pdf` & `Project_Background.pdf` - Detailed project documentation.
